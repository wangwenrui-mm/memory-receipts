# 数据说明

这个仓库里**包含数据**，所以需要说清楚：哪些是真的、哪些是造的、从哪来、能不能用、能不能删。

如果你只想知道结论：

- **不含任何个人隐私数据**（没有聊天记录、没有日记、没有信件、没有 API key）
- **`lab/data/corpus/` 是真实的第三方内容**（1000 篇 arXiv 论文的元数据与摘要），使用需注意许可
- **`lab/data/records*.jsonl` 和 `示例/` 下的是人为构造的示例数据**，不是真实实验结果
- **测试过程中产生的数据不在仓库里**，需要你自己跑出来

## 二、arXiv 语料（`lab/data/corpus/`）

### 来源

| 项 | 值 |
| --- | --- |
| 获取方式 | 通过 [arXiv API](https://info.arxiv.org/help/api/index.html)（`export.arxiv.org/api/query`）抓取 |
| 抓取时间 | 2026 年 10 月 |
| 数量 | 20 个分类 × 50 篇 = **1000 篇** |
| 分类 | cond-mat.mtrl-sci、cond-mat.supr-con、physics.app-ph、cond-mat.soft、physics.optics、q-bio.BM、cond-mat.mes-hall、physics.chem-ph、cond-mat.str-el、cond-mat.stat-mech、physics.comp-ph、eess.SP、physics.atom-ph、cond-mat.dis-nn、physics.bio-ph、cs.LG、cs.CL、cond-mat.quant-gas、physics.ins-det、nlin.PS |
| 字段 | `title` / `summary`（摘要）/ `author`（作者）/ `published`（日期）/ `id` / `category` |
| 作者条目 | 共 5,257 条（公开的论文署名信息） |

### 使用注意（重要）

1. **摘要的著作权属于论文作者**。这里保存的是 arXiv 公开提供的元数据与摘要，仅用于**检索与测试**，不用于再发布或商业用途。
2. 如需在论文中引用本语料，应引用**原论文**，而不是本仓库。
3. arXiv 的 API 使用条款要求遵守其请求频率与用途限制；本仓库只是一份**离线快照**，不再联网请求。
4. 作者姓名是**公开的学术署名信息**，不是隐私数据；但因涉及第三方，**如果你要再分发本仓库，建议保留本说明**。
5. 语料会随时间过期（arXiv 每日新增），仅代表 2026 年 10 月某一时刻的快照。

### 怎么重新抓

```bash
# 以某个分类为例（需要联网）
curl "https://export.arxiv.org/api/query?search_query=cat:cond-mat.mtrl-sci&start=0&max_results=50&sortBy=submittedDate&sortOrder=descending" \
  -o lab/data/corpus/cond-mat_mtrl-sci.xml
```

`lab/src/build_index.py` 会读取该目录下所有 `.xml` 建立索引。

## 三、示例数据（人为构造）

`lab/data/records*.jsonl`、`示例/*` 里的数值与"实验记录"**全部是编的**，用于：

- 演示核验流程（有依据 / 矛盾 / 未溯源 / 已过时）
- 演示记录格式（`id` / `param` / `value` / `unit` / `date` / `source` / `scope`）

**它们不对应任何真实实验，不能当作实验依据引用。**

字段格式见 [README](../README.md) 的「数据格式」与 `lab/README.md`。

## 四、测试过程中产生的数据

以下**不随仓库分发**，需要自己跑：

| 数据 | 怎么生成 | 落在哪 |
| --- | --- | --- |
| 自检结果 | `python tools/selftest.py` | 只打印到终端 |
| 加压测试结果 | `python tools/stress.py` | 只打印到终端 |
| 论文索引 | `python lab/src/build_index.py` | `lab/data/index/*.jsonl` |
| 核验报告 | `python lab/src/verify_doc.py 文件 记录` | 只打印到终端 |
| 验收数据 | `python lab/src/verify.py --acceptance` | 只打印到终端 |
| 随机压测数据 | `python lab/tests/gen200.py <种子>` | `lab/tests/round_<种子>.json` |

**"她"的真实数据（日记、信件、长期记忆、向量库、对话归档）从未进入本仓库**，全部只存在于原作者的本地 `data/` 目录。

## 五、脱敏说明

开源前做了以下处理（可对照 `git log` 与代码核查）：

| 项 | 处理 |
| --- | --- |
| 两个 QQ 号 + 机器人号 | 全部移除，改为环境变量 / 占位符 |

| `data/`、`logs/`、`backup/` | `.gitignore` 排除，且不在提交历史中 |
